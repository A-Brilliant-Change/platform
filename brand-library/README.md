# ABrilliantChange Brand Library

This folder is the repo-local staging area for a Microsoft 365-ready brand asset library.

## Purpose

Keep the platform, brand assets, and future presentation work aligned in one structure so both GitHub Copilot and Microsoft 365 Copilot can operate consistently.

## Structure

- 01-brand
- 02-hero
- 03-atlas
- 04-domains
- 05-infrastructure
- 06-ecosystem
- 07-origin
- 08-documentation

## Naming Convention

Use the same naming patterns as the public asset library and production repo:

- ABC-HERO-Master-Ceiling-Edition-v1.jpg
- ABC-ATLAS-Master-Transformation-Atlas-v1.jpg
- ABC-INFRASTRUCTURE-Explorer-Platform-v1.jpg
- ABC-ECOSYSTEM-Master-Overview-v1.jpg
- ABC-ORIGIN-Tulsa-Map-v1.jpg

## Workflow

1. Keep approved source assets in the repo under public/
2. Stage final brand assets here before moving them to SharePoint or OneDrive
3. Use this structure for proposal decks, executive summaries, and Copilot-assisted content

## Notes

This is a repo-local governance layer, not a replacement for the canonical public asset folder.
