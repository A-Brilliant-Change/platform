# Hero Images™

## Purpose

This directory contains official hero imagery used throughout the ABrilliantChange.com website experience.

Hero images represent the first visual impression of the ABC Transformation Operating System™ and serve as digital gateways into the organization's mission, vision, doctrine, and ecosystem.

These assets should communicate:

- Transformation
- Opportunity
- Infrastructure
- Innovation
- Leadership
- Community Impact
- Legacy

---

# Design Standards

Hero images should reflect the ABC visual language.

## Required Themes

- Bridges
- Pathways
- Infrastructure
- Community
- Opportunity
- Transformation
- Knowledge Networks
- Leadership
- Legacy

## Preferred Elements

- City skylines
- Sunrise and golden-hour lighting
- Infrastructure systems
- Knowledge graph connections
- Blueprint overlays
- Strategic planning motifs
- Institutional architecture

---

# Brand Alignment

All hero images should align with official brand standards and doctrine.

Related doctrine sources:

- Vision™
- Mission™
- Brand Essence™
- Core Values™
- Ten Pillars™
- Infrastructure of Transformation™

> Building Brighter Futures. Creating Opportunities. Designing Systems.

And:

> Building the Infrastructure of Transformation™.
