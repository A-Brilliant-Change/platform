# ABC Platform Asset Library™

## Purpose

This directory contains documentation supporting the production asset library used by the ABrilliantChange.com platform.

The Platform Asset Library serves as the operational bridge between:

```text
ABC Brand Identity System™

↓

Website Experience Assets™

↓

ABrilliantChange.com™

↓

ABC Transformation Operating System™
```

All assets within the platform repository should originate from approved assets maintained within the ABC Brand Identity System.

# Asset Governance

All production assets must:

✅ Follow ABC Brand Standards

✅ Be approved for production use

✅ Have version-controlled filenames

✅ Have a documented source location

✅ Be recorded in the Asset Manifest
